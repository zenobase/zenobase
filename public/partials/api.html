Authentication

Requests for protected resources must either include an OAuth 2 Authorization header:

Authorization: Bearer <access_token>

...or append the access token as a query parameter:

https://zenobase.com/...?code=<access_token>

Access tokens do not expire, but can be revoked any time.

Access tokens can be obtained by an implicit grant or a password grant.

Create an implicit grant

This authentication method allows a user to grant an application access to a single bucket.

In order to use this authentication method, an account with a validated email address is required.

The first step is to redirect the user to an authorization page:

https://zenobase.com/#/oauth/authorize?response_type=token&client_id=<client_id>&redirect_uri=<redirect_uri>
client_id
Your user ID (can be found in the account settings dialog).
redirect_uri
The page to which the user should be redirected back to. The domain must match the domain of your verified email address, unless the URI has a custom scheme that is prefixed with x-. If the address does not end with either # or ?, # is appended.

Upon authorization, the user is redirected to:

<redirect_uri#>code=<code>&scope=<scope>
code
The access token to use in the Authorization header.
scope
The bucket to which you have been granted access.

If the authorization fails for any reason other than an invalid redirect_uri, the user is redirected to:

<redirect_uri#>error=<error>&error_description=<error_description>
error
The error code:
invalid_request
The request is missing a required parameter.
unauthorized_client
The client is not authorized to request an access token using this method.
access_denied
The user denied the request.
unsupported_response_type
The response_type parameter must be set to token.
server_error
The request could not be processed. Try again later or contact support.
error_description
Optional description of the error.

Create a password grant

This authentication method grants full access to a user's account.

POST /oauth/token
Host: api.zenobase.com
Content-Type: application/x-www-form-urlencoded

grant_type=password&username=<username>&password=<password>
username
The user's name.
password
The user's password.
Example:
Request
curl -i -X POST 'https://api.zenobase.com/oauth/token' \
  -d 'grant_type=password&username=jdoe&password=secret1337'

Response
HTTP/1.1 200 OK
Content-Type: application/json

{
  "access_token" : "e7975e8bb6mabc3ek567",
  "client_id" : "args4iqh2c"
}

Revoke a grant

DELETE /authorizations/<access_token>
Host: api.zenobase.com
Authorization: Bearer <access_token>
access_token
The access token associated with the grant to revoke.
Example:
Request
curl -i -X DELETE 'https://api.zenobase.com/authorizations/e7975e8bb6eabc3ef567' \
  -H 'Authorization: Bearer e7975e8bb6eabc3ef567'

Response
HTTP/1.1 204 No Content

Buckets

Buckets are containers for events, but also include permissions and dashboard settings.

List buckets

GET /users/<user_id>/buckets/?offset=<offset>&limit=<limit>
Host: api.zenobase.com
Authorization: Bearer <access_token>
user_id
The user whose buckets we want to retrieve.
offset
How many buckets to skip. Defaults to 0.
limit
The number of buckets to return, up to 100. Defaults to 10.
Example
Request
curl -i 'https://api.zenobase.com/users/args4iqh2c/buckets/?limit=10' \
  -H 'Authorization: Bearer e7975e8bb6eabc3ef567'

Response
HTTP/1.1 200 OK
Content-Type: application/json

{ 
  "total" : 1,
  "buckets" : [
    { 
      "@id" : "jl2rg0o36e",
      "version" : 1,
      "label" : "My Data",
      "created" : "2012-10-18T20:59:36.295Z", 
      "size" : 4
      "roles" : [
        { "principal" : "args4iqh2c", "role" : "owner" }
      ]
    }
  ]
}

Create a bucket

Content-Type: application/json
Host: api.zenobase.com
Authorization: Bearer <access_token>

{ 
  "label" : <label>,
  "description" : <description>,
  "aliases" : [
    { "@id" : <bucket_id> },
    { "@id" : <bucket_id> },
    ...

label
A human-readable name for the bucket. Required, 1-20 characters from a-zA-Z0-9-_ .
description
One or two sentences describing this bucket. Optional.

Update a bucket

Update a bucket's metadata, i.e. its label, description, roles and widgets.

PUT /buckets/<bucket_id>
Content-Type: application/json
Host: api.zenobase.com
Authorization: Bearer <access_token>

{ 
  "label" : <label>,
  "description" : <description>,
  "roles" : [
    {
      "principal" : <user_id>,
      "role" : <'owner'|'viewer'>
    },
    ...
  ],
  "widgets" : [
    ...
  ]
}
bucket_id
The bucket to update.
Example:
Request
curl -i -X PUT 'https://api.zenobase.com/buckets/v7jg3l5ibc' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer e7975e8bb6eabc3ef567 \  
  -d '{
    "label" : "Updated Bucket",
    "description" : "This bucket is public!",
    "roles" : [
      { "principal" : "args4iqh2c", "role" : "owner" },
      { "principal" : "*", "role" : "viewer" }
    ]
  }'

Response
HTTP/1.1 204 No Content
Content-Type: application/json
X-Command-ID: 4o6iqmpnrr

Events

Events contain the actual data being tracked.

List events

GET /buckets/<bucket_id>/?offset=<offset>&limit=<limit>&order=<order>&reverse=<reverse>&facet=<facet_expression>&q=<constraint_expression>
Host: api.zenobase.com
Authorization: Bearer <access_token>
bucket_id
The bucket from which to retrieve events.
offset
The offset of the first event. Defaults to 0.
limit
How many events to return. If no limit and no facets are specified, a list of all matching events is returned.
order
The field to sort on. Defaults to timestamp.
reverse
Sort in ascending order. Defaults to false
facet_expression
See facets. More than one facet parameter can be given.
constraint_expression
See constraints. Optional. If more than one constraint parameter is present, all constraints must be fulfilled.
Example:
Request
curl -i 'http://api.zenobase.com/buckets/v7jg3l5ibc/?offset=0&limit=10&facet=id:tags,type:count&q=tag:lunch' \
  -H 'Authorization: Bearer e7975e8bb6eabc3ef567'

Response
HTTP/1.1 200 OK
Content-Type: application/json

{
  "total" : 42,
  "events": [ 
    { 
      "timestamp" : [ "20121024T13:10:00.000-07:00" ],
      "tag" : [ "lunch", "thai" ],
      "author" : "7ghkds6jar",
      ...
    },
    ...
  ],
  "tags": [ 
    { "label" : "lunch", "count" : 10 },
    { "label" : "thai", "count" : 1 },
    ...
  ]
}

Ranges

The begin or end of a range expressions can be open, inclusive or exclusive:

[a..b]
values not smaller than a and not larger than b
[a..b)
values not smaller than a but smaller than b
(a..b]
values larger than a but not larger than b
(a..b)
values larger than a and smaller than b
[a..*)
values not smaller than a
(*..b]
values not larger than b

Special Fields

_timestamp
The last modification time of an item. For example, _timestamp:[2013TZ..*) matches items that have been modified since the beginning of 2013.

Facets

Facets can be used to specify what data to return e.g. when listing events.

id:<id>,type:<type>,<param:value>,...
id
A short string, used to identify the facet's data in the result.
type
The facet type, see below.
param:value
Type-specific parameters for the facet, see below.
 

Count Facet

field=<'tag'|'author'>
The field to aggregate on. Required.
order=<'count'|'term'>
Order results by count or alphabetic. Defaults to count.
offset=<integer>
The offset of the first result. Defaults to 0.
limit=<integer>
How many results to return. Defaults to 10.
reverse=<boolean>
Sort in descending order. Defaults to false
Example:
Response
id:xyz,type:count,field:tag

Request
"xyz" : [
  { "label" : "lunch", "count" : 31 },
  { "label" : "dinner", "count" : 22 },
  { "label" : "breakfast", "count" : 19 }
]
 

Timeline Facet

field=<String>
The field containing the values. Required.
unit=<String>
The unit of the value. Required for fields with units.
interval=<'year'|'month'|'day'|'hour'|'minute'>
The interval at which values are aggregated. Defaults to month.
timezone=<Z>
Optional timezone offset, e.g.+00:00. If not set, values are aggregated using their local time.
filter=<constraint>
Optional constraint.
Example:
Request
id:xyz,type:timeline,field:count,filter:tag:steps

  ...
]

Controls the clustering, from 0.0 (show each point) to 1.0 (one big cluster). Defaults to 0.2.
Example:
Request
id:xyz,type:map,factor:0.4

Response
"xyz" : [
  { "count" : 1, "lat" : -2.8, "lon" : -40.48 },
  { "count" : 14, "lat" : 14.895, "lat_max" : 16.512, "lat_min" : -3.784, "lon" : -61.823, "lon_max" : -61.048, "lon_min" : -64.950 },
  ...
]
 

Ratings Facet

scale=<Integer>

Scoreboard Facet

key_field=<'author'|'tag'>
The field to aggregate on. Required.
value_field=<String>
The field containing the values. Required.
unit=<String>
The unit of the value. Required for fields with units.
order=<'count'|'term'>
Order results by count or alphabetic. Defaults to count.
limit=<integer>
How many results to return. Defaults to 10.

  ...
]
 

Scatter Plot Facet

field_x=<String>
The field for the x series. Required.
unit_x=<String>
The unit for the x series. Required for fields with units.
statistic_x=<'count'|'avg'|'min'|'max'|'sum'>
The aggregate function for the x series. Defaults to avg.
filter_x=<constraint>
Optional constraint for the x series.
field_y=<String>
The field for the y series. Required.
unit_y=<String>
The unit for the y series. Required for fields with units.
statistic_y=<'count'|'avg'|'min'|'max'|'sum'>
The aggregate function for the y series. Defaults to avg.
filter_y=<constraint>
Optional constraint for the y series.
interval=<'year'|'month'|'day'|'hour'|'minute'>
The interval at which values are aggregated. Defaults to day.
timezone=<Z>
The timezone offset to use. Defaults to +00:00
lag=<Integer>
The number of time units (see interval) by which to offset the y series values from the x series values. Defaults to 0
Example:
Request
id:xyz,type:scatterplot,field_x:duration,field_y:duration,statistic:sum,interval:day,lag:1

Response
"xyz" : [
  [ 2.826E+7, 2.592E+7 ],
  [ 2.898E+7, 2.826E+7 ],
  [ 3.126E+7, 2.898E+7 ],
  ...
]
 

Gantt Facet

field=<String>
The field containing the values. Required.
order=<'count'|'term'|'min'|'max'>
Order results by count, alphabetic, or be earliest or latest time. Defaults to term.
limit=<integer>
How many results to return. Defaults to 10.
timezone=<Z>

Request

  ...
]

Polar Facet

key_field=<String>
A field containing a timestamp. Defaults to timestamp.
value_field=<String>
A field containing the values to be aggregated. Optional; if not set, only a count is returned for each interval.
unit=<String>
The unit of the values. Required for fields with units.
interval=<'hour_of_day'|'day_of_week'|'day_of_month'|'day_of_year'|'month_of_year'>
The (local, timezone-independent) interval to aggregate on. Required.
filter=<constraint>
Optional constraint.
Example:
Request
id:xyz,type:polar,interval:day_of_week

Response
"xyz" : [
  { "value" : 1, "label" : "Mon", "count" : 26 },
  { "value" : 2, "label" : "Tue", "count" : 14 },
  { "value" : 3, "label" : "Wed", "count" : 10 },
  ...
]

Errors

The following error codes could be returned for most requests:

400 Bad Request
Invalid or missing parameters or request body; check the response body for an explanation.
401 Unauthorized
Missing Authentication header.
403 Forbidden
Authentication failed, or insufficient permissions.
404 Not Found
The requested resource doesn't exist.
409 Conflict
Trying to update a stale resource.
500 Internal Server Error
Shouldn't happen; please contact us.
503 Service Unavailable
The site is down for maintenance or overloaded; contact us if this lasts longer than a few minutes.

The response may contain a body with a description of the problem:

{
  "message" : <String>
}
