Authentication

Requests for protected resources must either include an OAuth 2 Authorization header:

Authorization: Bearer <access_token>

...or append the access token as a query parameter:

https://zenobase.com/...?code=<access_token>

Access tokens do not expire, but can be revoked any time.

Access tokens can be obtained by an implicit grant or a password grant.

Implicit Grant

This authentication method allows a user to grant an application access to a single bucket.

In order to use this authentication method, an account with a validated email address is required.

The first step is to redirect the user to an authorization page:

https://zenobase.com/#/oauth/authorize?response_type=token&client_id=<client_id>&redirect_uri=<redirect_uri>
client_id
Your user ID (hidden behind the icon on your profile page).
redirect_uri
The page to which the user should be redirected back to. The domain must match the domain of your verified email address. If the address does not end with either # or ?, # is appended.

Upon authorization, the user is redirected to:

<redirect_uri#>code=<code>&scope=<scope>
code
The access token to use in the Authorization header.
scope
The bucket to which you have been granted access.

If the authorization fails for any reason other than an invalid redirect_uri, the user is redirected to:

<redirect_uri#>error=<error>&error_description=<error_description>
error
The error code:
invalid_request
The request is missing a required parameter.
unauthorized_client
The client is not authorized to request an access token using this method.
access_denied
The user denied the request.
unsupported_response_type
The response_type parameter must be set to token.
server_error
The request could not be processed. Try again later or contact support.
error_description
Optional description of the error.

Password Grant

This authentication method grants full access to a user's account.

POST /oauth/token
Host: api.zenobase.com
Content-Type: application/x-www-form-urlencoded

grant_type=password&username=<username>&password=<password>
username
The user's name.
password
The user's password.

Example

Request
curl -i -X POST 'https://api.zenobase.com/oauth/token' \
  -d 'grant_type=password&username=jdoe&password=secret1337'
Response
HTTP/1.1 200 OK
Content-Type: application/json

{
  "access_token" : "e7975e8bb6mabc3ek567",
  "client_id" : "args4iqh2c"
}

Buckets

Buckets are containers for events, but also include permissions and dashboard settings.

List buckets

GET /buckets/?q=roles.principal:<user_id>&offset=<offset>&limit=<limit>
Host: api.zenobase.com
Authorization: Bearer <access_token>
user_id
The user whose buckets we want to retrieve. Required.
offset
How many buckets to skip. Defaults to 0.
limit
The maximum number of buckets to return. Required.

Example

Request
curl -i 'https://api.zenobase.com/buckets/?q=roles.principal:args4iqh2c&limit=10' \
  -H 'Authorization: Bearer e7975e8bb6eabc3ef567'
Response
HTTP/1.1 200 OK
Content-Type: application/json

{ 
  "total" : 1,
  "buckets" : [
    { 
      "@id" : "jl2rg0o36e",
      "version" : 1,
      "label" : "My Data",
      "created" : "2012-10-18T20:59:36.295Z", 
      "size" : 4
      "roles" : [
        { "principal" : "args4iqh2c", "role" : "owner" }
      ]
    }
  ]
}

Get a single bucket

Get the metadata for a single bucket.

GET /buckets/<bucket_id>
Authorization: Bearer <access_token>
bucket_id
The bucket we want to retrieve.

Example

Request
curl -i GET 'http://api.zenobase.com/buckets/v7jg3l5ibc' \
  -H 'Authorization: Bearer e7975e8bb6eabc3ef567'
Response
HTTP/1.1 200 OK
Content-Type: application/json

{
  "@id" : "v7jg3l5ibc",
  "created" : "2012-10-24T23:01:44.438Z",
  "label" : "Test Bucket",
  "description" : "This bucket is for testing."
  "roles": [
    { "principal" : "args4iqh2c" , "role" : "owner" }

Create a bucket

POST /buckets/
Content-Type: application/json
Host: api.zenobase.com
Authorization: Bearer <access_token>

{ 
  "label" : <label>,
  "description" : <description>
}
label
A human-readable name for the bucket. Required, 1-20 characters from a-zA-Z0-9-_ .
description
One or two sentences describing this bucket. Optional.

  -H 'Content-Type: application/json' \

    "label" : "Test Bucket",
    "description" : "This bucket is for testing."
  }'

Location: /buckets/v7jg3l5ibc

  "@id" : "v7jg3l5ibc",

Update a bucket

Update a bucket's metadata, i.e. its label, description, roles and widgets.

PUT /buckets/<bucket_id>
Content-Type: application/json
Host: api.zenobase.com
Authorization: Bearer <access_token>

{ 
  "label" : <label>,
  "description" : <description>,
  "roles" : [
    {
      "principal" : <identity>,
      "role" : <'owner'|'viewer'>
    },
    ...
  ],
  "widgets" : [
    ...
  ]
}
bucket_id
The bucket to update.

Example

Request
curl -i -X PUT 'https://api.zenobase.com/buckets/v7jg3l5ibc' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer e7975e8bb6eabc3ef567 \  
  -d '{
    "label" : "Updated Bucket",
    "description" : "This bucket is public!",
    "roles" : [
      { "principal" : "args4iqh2c", "role" : "owner" },
      { "principal" : "*", "role" : "viewer" }
    ]
  }'
Response
HTTP/1.1 204 No Content
Content-Type: application/json
X-Command-ID: 4o6iqmpnrr

Events

Events contain the actual data being tracked.

List events

GET /buckets/<bucket_id>/?w=<facet_expression>&q=<constraint_expression>
Host: api.zenobase.com
Authorization: Bearer <access_token>
bucket_id
The bucket from which to retrieve events.
facet_expression
See facets. If no facets are specified, a list of all matching events is returned. More than one facet parameter can be given.
constraint_expression
See constraints. Optional. If more than one constraint parameter is present, all constraints must be fulfilled.

Example

Request
curl -i 'http://api.zenobase.com/buckets/v7jg3l5ibc/?w=id:a,type:list&w=id:b,type:count&q=tag:lunch' \
  -H 'Authorization: Bearer e7975e8bb6eabc3ef567'
Response
HTTP/1.1 200 OK
Content-Type: application/json

{
  "total" : 42,
  "a": [ 
    { 
      "timestamp" : [ "20121024T13:10:00.000-07:00" ],
      "tag" : [ "lunch", "thai" ],
      "author" : "7ghkds6jar",
      ...
    },
    ...
  ],
  "b": [ 
    { "label" : "lunch", "count" : 10 },
    { "label" : "thai", "count" : 1 },
    ...
  ]
}

Query Constraints

Constraints can be used to restrict lists of events.

<field>:<expression>
field
The field name.
expression
Type-specific expression.

Expressions

tokens
foo
exact match
foo*
prefix match
text
foo
exact match on a word
foo*
prefix match on a word
timestamps
2013TZ
[2013TZ..2014TZ)
all of 2013
2013-01TZ
[2013-01TZ..2013-02TZ)
January
2013-01-02TZ
[2013-01-02TZ..2013-01-03TZ)
January 2nd
2013-01-02T20Z
[2013-01-02T20Z..2013-01-02T21Z)
8-9pm
2013-01-02T20:05Z
[2013-01-02T20:05Z..2013-01-02T20:06Z)
8:05-8:06pm
2013-01-30T23:00:00.000TZ
2013-01-30T15:00:00.000T-08:00
1359586800000
an exact moment
locations
25.787,-122.333,47.610,-80.224
points in the area between Seattle and Miami
36.08,-115.17~100 mi
point within 100 miles of Las Vegas
numbers
80
exact match
(80..100]
larger than 80, but not larger than 100
measures
10 lb
10 lb, or 4.54 kg (or equivalent)
[10 lb..20 lb]
not less than 10, and not more than 20 lb (or equivalent)
durations
1h 30min
1 hour and 30 minutes, or 90 minutes
[1h..1d]
not less than 1 hour, and not more than 1 day

Ranges

The begin or end of a range expressions can be open, inclusive or exclusive:

[a..b]
values not smaller than a and not larger than b
[a..b)
values not smaller than a but smaller than b
(a..b]
values larger than a but not larger than b
(a..b)
values larger than a and smaller than b
[a..*)
values not smaller than a
(*..b]
values not larger than b

Query Facets

Facets can be used to specify what data to return when listing events.

id:<id>,type=<type>,<param=value>,...
id
A short string, used to identify the widget's data in the result.
type
The widget type, see below.
param=value
Type-specific parameters for the widget, see below.

Types

list
offset=<integer>
The offset of the first event. Default is 0.
limit=<integer>
How many events to return. Default is 10.
order=<field name>
The field to sort on. Default is timestamp.
reverse=<boolean>
Sort in ascending order. Default is false
count
field=<'tag'|'author'>
The field to aggregate on. Required.
order=<'count'|'term'>
Order results by count or alphabetic. Default is by count.
offset=<integer>
The offset of the first result. Default is 0.
limit=<integer>
How many results to return. Default is 10.
reverse=<boolean>
Sort in descending order. Default is false
timeline
interval=<'year'|'month'|'day'|'hour'|'minute'>
The interval at which values are aggregated. Default is month.
timezone=<Z>
The timezone offset to use. Default is +00:00
map
factor=<Number>
Controls the clustering, from 0.0 (show each point) to 1.0 (one big cluster). Default is 0.2.
ratings
scale=<Integer>
The number of groups to sort the ratings into. Defaults to 5 (i.e. 0 to 5 stars).
scoreboard
key_field=<'author'|'tag'>
The field to aggregate on. Required.
value_field=<String>
The field containing the values. Required.
unit=<String>
The unit of the value. Required for fields with units.
order=<'count'|'term'>
Order results by count or alphabetic. Default is by count.
limit=<integer>
How many results to return. Default is 10.
gantt
field=<String>
The field containing the values. Required.
order=<'count'|'term'>
Order results by count or alphabetic. Default is by term.
limit=<integer>
How many results to return. Default is 10.
timezone=<Z>
The timezone offset to use. Default is +00:00
histogram
field=<String>
The field containing the values. Required.
unit=<String>
The unit of the value. Required for fields with units.
interval=<Integer>
The bucket size. Default is 10.
time_histogram
interval=<'hour_of_day'|'day_of_week'|'month_of_year'>
The time interval to aggregate on. Required.
timezone=<Z>
The timezone offset to use. Default is +00:00

Errors

The following error codes could be returned for most requests:

400 Bad Request
Invalid or missing parameters or request body; check the response body for an explanation.
401 Unauthorized
Missing Authentication header.
403 Forbidden
Authentication failed, or insufficient permissions.
404 Not Found
The requested resource doesn't exist.
409 Conflict
Trying to update a stale resource.
500 Internal Server Error
Shouldn't happen; please contact us.
503 Service Unavailable
The site is down for maintenance or overloaded; contact us if this lasts longer than a few minutes.

In some cases, the response may contain a body with a problem description:

{
  "message" : <String>
}
